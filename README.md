### Things I've been building

**[OpenKinematics](https://github.com/devwithchai/OpenKinematics)**
A Python library for robot kinematics, dynamics and visualization — built from first principles, mainly as a way to go deeper into the mathematics behind robotics.

**Tendon-Driven Soft Robotic Finger**
A personal project exploring tendon-driven actuation, soft robotics and dynamic simulation.

**Mobile Robotics**
Working with differential-drive robots, embedded controllers, sensors and ROS 2 — moving from basic Arduino prototypes toward more capable robotic systems.

### My approach

I like building small systems, breaking them, figuring out why they broke, and then rebuilding them properly.

I’m especially interested in the space where:

`mathematics → algorithms → simulation → hardware`

meet each other.
